Правила

Телефоны

У каждого телефона своя служба в отдельном процессе: своё расписание, своя очередь, свои вкусы. Они работают одновременно — пока один публикует, другой смотрит ленту.

Журнал службы

Что смотреть

Тема — своими словами, модель сверяет её с роликом по смыслу. Тем можно несколько через запятую, тогда достаточно совпадения по любой. Пусто — значит не проверять.

Как это работает

Совпали и тема, и язык — смотрю 20-30 секунд, могу лайкнуть.
Совпала тема (любая из списка), но язык чужой — 10-15 секунд, без лайка.
Совпал только язык — 1,5-10 секунд, без лайка.
Не совпало ничего — листаю сразу.

Короткий ролик не кручу по второму разу: как только он пошёл на второй круг, листаю дальше.

Нейросеть для разбора роликов

Модель смотрит на кадр и говорит, о чём ролик. Считать может сервер в твоей сети или сервис по API — разговор с ними одинаковый, отличаются только адрес, ключ и имя модели.

Этого достаточно: сервис, адрес и модель определятся по самому ключу, зрение переключится на него, а ключ тут же проверится живым запросом — ответ скажет, принят он или нет. Всё, что ниже, нужно только для настройки вручную.

Телефоны

У каждого телефона своё хозяйство: очередь, расписание, вкусы и сводка. Переключаться между ними — кружками на главной, над выбором ленты. Тут просто видно, кто на связи.

Клавиатура для русских описаний

Штатный ввод adb умеет только латиницу. Если клавиатура установлена, но выключена — кнопка включит её.

Telegram-бот

…

Кидаешь боту видео с подписью — оно уходит в публикацию. Подпись становится описанием поста.

Владельца бот запоминает сам: после запуска напиши ему любое сообщение, и он привяжется к твоему чату. Чужие останутся без ответа.

Как он решает, куда и когда

Куда. Сети можно назвать прямо в подписи: «tiktok», «шортс», «#reels». Не названы — публикует во все. Служебные слова из описания вырезаются.

Когда. Написал время («в 18:30») — поставит на него. Времени нет и расписание публикаций пустое — публикует сразу. Расписание задано — дождётся ближайшего часа.
